## 一、需求概述

| 需求 | 描述 |
|------|------|
| R1 托盘图标 | 软件启动时自动创建系统托盘图标 |
| R2 关闭行为可选 | 关闭窗口时，可选择"退出"或"最小化到系统托盘"，在设置中可配置 |
| R3 单实例 | 新启动的实例检测已有实例，通过 IPC 委托操作（打开文件等），自身退出 |
| R4 启动时最小化 | 可设为启动时不显示主窗口，仅在系统托盘显示图标 |
| R5 托盘操作 | 左键单击显示窗口，右键弹出菜单（显示窗口/新建/打开/退出） |

### 1.1 交互流程

```
启动 →
    单实例检测（QSharedMemory）
    ├── 已有实例 → 发送 IPC 消息 → sys.exit(0)
    └── 无实例 → 创建 QLocalServer
                 → 创建托盘图标
                 → 创建 MainWindow
                 → 根据配置 show() 或 hide()

关闭 →
    closeEvent 触发
    ├── close_to_tray == true → 检查未保存 → hide() → 托盘气泡通知
    └── close_to_tray == false → 现有退出逻辑（保持不变）

托盘菜单 →
    ├── "显示主窗口" → show() + raise() + activateWindow()
    ├── "新建文件"   → new_file()
    ├── "打开文件..." → open_file()
    └── "退出"       → 完整退出流程（含未保存检查）

托盘左键单击 → 总是显示窗口（bring_to_front）
```

#### 3.3.2 `try_lock()` 核心流程

```
try_lock():
1. if _shared_mem.attach() 成功:
   → 已有实例运行, detach() 后 return False

2. if _shared_mem.error() == QSharedMemory.KeyExists:
   → 崩溃残留锁, attach() + detach() 清理, 重试 create()

3. _shared_mem.create(1)  → 创建 1 字节锁
   if 失败 → return False (罕见 OS 级错误)

4. _server.listen(_server_name)
   if 失败 → detach() + return False

5. _server.newConnection.connect(_on_new_connection)
6. return True
```

#### 3.3.3 IPC 帧协议

```
[4字节大端N][N字节UTF-8 JSON]

请求帧:
    {"action":"open_files","files":["p1","p2"],"line":10,"column":5}
    {"action":"bring_to_front"}
确认帧:
    "ok" (2 字节)
```

#### 3.3.4 `send_message()` 核心流程

```
send_message(data: dict) → bool:
1. socket = QLocalSocket()
2. socket.connectToServer(_server_name, QLocalSocket.OpenWhenExistsFlag)
3. if not socket.waitForConnected(IPC_TIMEOUT_MS):
   → 日志 ERROR, return False
4. frame = pack_header(len(json_bytes)) + json_bytes
5. socket.write(frame)
6. if not socket.waitForBytesWritten(IPC_TIMEOUT_MS):
   → 日志 ERROR, return False
7. if not socket.waitForReadyRead(IPC_TIMEOUT_MS):
   → 日志 WARNING, return True (消息已发出, 确认可能丢)
8. response = socket.readAll()
9. socket.disconnectFromServer()
10. return True
```

#### 3.3.5 `_on_new_connection()` + `_read_message()`

```
_on_new_connection():
    socket = _server.nextPendingConnection()
    socket.readyRead.connect(lambda: _read_message(socket))

_read_message(socket):
    buffer 累积:
    1. 先读满 HEADER_SIZE 字节
       → struct.unpack("!I") → payload_length
    2. 再读满 payload_length 字节
    3. json.loads() → data dict
       → emit message_received(data)
       → socket.write(b"ok")  # 确认回复
    4. socket.disconnectFromServer()
    
    try-except 包裹:
    - JSONDecodeError → 日志 WARNING, 丢弃
    - 截断/格式错 → 日志 WARNING, 丢弃
    - 任何异常 → 日志 ERROR, 关闭连接
```

#### 3.3.6 `release()`

```python
def release(self):
    self._server.close()
    if self._shared_mem.isAttached():
        self._shared_mem.detach()
    self._logger.info("单实例守护已释放")
```

```python
def _confirm_close_unsaved_all_tabs(self, unsaved: list) -> str | None:
    """对一批未保存标签弹出三选一对话框

    names = []
    for tab in unsaved:
        fp = tab.get("file_path")
        names.append(os.path.basename(fp) if fp else "未命名")

    more = f"\n... 等共 {len(unsaved)} 个文件" if len(unsaved) > 10 else ""

        f"以下 {len(unsaved)} 个文件有未保存的更改：\n\n"

    msg.yesButton.setMinimumWidth(80)
    msg.cancelButton.setMinimumWidth(80)
```

#### 4.2.7 IPC 消息处理

```python
@pyqtSlot(dict)
def _on_instance_message(self, message: dict):
    """处理来自第二实例的 IPC 消息

    @param message: 消息字典, 包含 action 字段
    """
    action = message.get("action", "")
    self._logger.info(f"接收到 IPC 消息: {action}")

    if action == "open_files":
        files = message.get("files", [])
        line = message.get("line")
        column = message.get("column")

        # 复用 CLI 参数的处理逻辑
        from src.infrastructure.cli_args import ParsedArgs
        ipc_args = ParsedArgs(
            files=files, line=line, column=column,
        )
        self._handle_external_files(ipc_args)

        # 将窗口带到前台
        self._bring_to_front()

    elif action == "bring_to_front":
        self._bring_to_front()
```

#### 4.2.8 文件打开逻辑提取

将 `_process_cli_args` 中打开文件的核心逻辑提取为可复用方法：

```python
def _handle_external_files(self, args: "ParsedArgs"):
    """处理外部传入的文件打开请求（CLI 或 IPC）

    @param args: 命令行参数（或 IPC 参数）
    """
    if not args.files:
        return

    if self._tab_manager.tab_count() == 1:
        editor = self._tab_manager.get_editor(0)
        file_path = self._tab_manager.get_file_path(0)
        if editor and file_path is None and not editor.document().isModified():
            self._tab_manager.close_tab(0)

    first_tab_index = -1
    for i, file_path in enumerate(args.files):
        if os.path.exists(file_path):
            content, encoding, _, err = self._file_service.open_file(
                file_path, encoding=args.encoding,
            )
            if err:
                self._logger.warning(
                    f"外部文件打开失败: {file_path}, error={err}"
                )
                self._signal_bus.status_message.emit(
                    f"打开失败: {os.path.basename(file_path)}",
                    AppConstant.STATUS_MESSAGE_DURATION_MS,
                )
                continue
            use_encoding = args.encoding if args.encoding else encoding
            index = self._tab_manager.create_tab(
                file_path=file_path, content=content,
                encoding=use_encoding,
            )
        else:
            index = self._tab_manager.create_tab(
                file_path=None, content="",
                encoding=args.encoding or "utf-8",
            )

        if i == 0:
            first_tab_index = index

    if first_tab_index >= 0 and (args.line is not None or args.column is not None):
        self._apply_cursor_position(first_tab_index, args.line, args.column)

    if first_tab_index >= 0:
```

## 六、入口改造 `main.py`

```python
def _launch_main_window(args: ParsedArgs):
    from PyQt5.QtCore import qInstallMessageHandler, QtMsgType, QTimer
    from PyQt5.QtWidgets import QApplication
    from qfluentwidgets import setTheme, Theme
    from src.infrastructure.logger import start_logger, stop_logger, get_logger

    app = QApplication(sys.argv)
    app.setApplicationName("GlassEditor")
    app.setApplicationVersion("1.0.0")
    app.setOrganizationName("GlassEditor")

    # 安装 Qt 消息处理器（现有代码）
    def _qt_message_handler(msg_type, context, msg):
        if "Unknown property" in msg:
            return
    qInstallMessageHandler(_qt_message_handler)

    setTheme(Theme.DARK)
    start_logger()
    logger = get_logger("Main")
    logger.info("GlassEditor starting...")
    logger.info(f"CLI args: {args}")

    # ════════════════════════════════════════════
    # 单实例守护
    # ════════════════════════════════════════════
    from src.infrastructure.single_instance import SingleInstanceGuard
    from src.infrastructure.app_constants import AppConstant

    guard = SingleInstanceGuard(AppConstant.IPC_SERVER_NAME)

    if not guard.try_lock():
        # ── 已有实例运行: 发送 IPC 消息后退出 ──
        logger.info("检测到已有实例运行, 通过 IPC 委托操作")

        message = {
            "action": "open_files",
            "files": args.files,
            "line": args.line,
            "column": args.column,
        }
        success = guard.send_message(message)

        if not success:
            # IPC 通信失败: 弹出对话框让用户选择
            from PyQt5.QtWidgets import QMessageBox
            reply = QMessageBox.question(
                None, "通信失败",
                "无法连接到已运行的编辑器实例。\n"
                "是否仍然启动新实例？",
                QMessageBox.Yes | QMessageBox.No,
                QMessageBox.No,
            )
            if reply == QMessageBox.No:
                guard.release()
                stop_logger()
                sys.exit(1)
            # Yes → 降级为多实例启动
            logger.warning("IPC 通信失败, 以降级模式启动新实例")
        else:
            guard.release()
            stop_logger()
            sys.exit(0)

    # ── 本进程为主实例: 正常启动 ──
    logger.info("单实例锁定成功, 本进程为主实例")

    from src.ui.main_window import MainWindow
    window = MainWindow(cli_args=args, single_instance_guard=guard)

    # 连接 IPC 消息
    guard.message_received.connect(window._on_instance_message)

    # ── 启动时最小化判定 ──
    start_minimized = window.is_start_minimized_to_tray()

    if not start_minimized:
        window.show()
    else:
        # 先 show() 保证窗口和子组件初始化完整, 再立刻隐藏
        window.show()
        QTimer.singleShot(0, window.hide)

    logger.info("GlassEditor started")

    exit_code = app.exec_()

    # 清理
    if window._tray_icon:
        window._tray_icon.hide()
    guard.release()
    stop_logger()
    sys.exit(exit_code)
```

## 八、健壮性分析

### 8.1 边界情况清单

| # | 场景 | 处理 | 测试要点 |
|---|------|------|----------|
| B1 | 系统无托盘环境 | `isSystemTrayAvailable()` → `_tray_icon = None`, `CLOSE_TO_TRAY` 配置被忽略（fallback 到退出模式） | 远程桌面下关闭窗口 |
| B2 | IPC 超时 | `waitForConnected(3000)` 超时 → `send_message()` 返回 False, 弹出对话框让用户选择 | 锁住主实例端口, 启动第二实例 |
| B3 | 进程崩溃 QSharedMemory 残留 | `attach()` 失败且 `error()==KeyExists` → `detach()` 清理 → 重试 `create()` | 任务管理器杀进程后立刻重启 |
| B4 | 两次启动竞争条件 | `QSharedMemory.create()` OS 原子操作, 唯一成功者创建 QLocalServer | 批量同时启动 |
| B5 | 托盘隐藏 + CLI 打开文件 | IPC 委托 → `open_files` → `bring_to_front` | 文件关联双击测试 |
| B6 | 托盘退出 + 未保存文件 | `quit_requested` → `close()` → `closeEvent` 完整退出逻辑 | 修改文件后从托盘退出 |
| B7 | 隐藏态被任务管理器杀进程 | `QSharedMemory` OS 自动释放, session.json 已由 30s 循环保存 | 无残留 |
| B8 | 坏消息/截断数据 | JSON 解析 `try-except` → 日志 WARNING → 丢弃 + 关闭连接 | 手动发错误数据到 named pipe |
| B9 | 第二实例在 IPC 过程中退出 | `waitForReadyRead` 超时但不影响主实例 | 强行终止第二实例进程 |
| B10 | IPC 帧中文件路径不存在 | 打开流程中 `os.path.exists()` 检查 → 跳过 + 日志 WARNING | 发送不存在的路径 |

### 8.2 安全性

| 方面 | 措施 |
|------|------|
| IPC 仅限本地 | QLocalServer 使用命名管道（Windows）或 Unix domain socket, 不接受远程连接 |
| 输入验证 | JSON 解析后检查 `action` 字段存在且为字符串, 否则丢弃 |
| 路径卫生 | 接收的文件路径经 `os.path.isabs()` + `os.path.exists()` 验证 |
| 日志脱敏 | 文件路径含用户名的部分需脱敏处理, 遵循日志系统设计规范 |
| 配置安全 | `CLOSE_TO_TRAY` / `START_MINIMIZED_TO_TRAY` 为公开级别配置, 无敏感信息 |

### 8.3 性能分析

| 方面 | 影响 | 说明 |
|------|------|------|
| QSharedMemory 1 字节锁 | 可忽略 | 仅启动时 attach/create, 零运行时开销 |
| IPC 消息 | 每次启动 < 3ms | 仅第二实例启动时触发, JSON < 1KB |
| 托盘图标 | 空闲 0% CPU, < 1MB 内存 | QSystemTrayIcon 由 Qt 事件驱动, 无轮询 |
| closeEvent 检查 | 临时的 < 10ms | 仅用户关闭时触发 |
