# UI 设计规范

## 1. 设计原则

**设计语言**：Microsoft Fluent Design System。核心理念——**轻盈**：减少视觉噪音，内容为焦点；**通透**：使用亚克力和模糊传达层次感；**一致**：统一设计决策系统；**响应**：布局自适应窗口尺寸变化。

**设计令牌**：所有颜色、间距、圆角、字号通过集中令牌系统管理，禁止使用魔法值。

---

## 2. 颜色系统

### 2.1 色调原则

- **主色调（Accent）**：用于选中项、链接、按钮强调。暗色模式与亮色模式主色调一致。
- **语义色**：成功/警告/错误/信息四类状态色，跨模式保持一致。
- **背景层**：分三层次（主/次/三级），暗色模式下编辑器背景略深于 UI 背景，以产生层次感。亮色模式相反。
- **文字层**：分主文字/次要文字/禁用文字三级。暗色模式下浅色文字，亮色模式下深色文字。
- **边框层**：默认/次要/聚焦/错误四类边框，聚焦色与主色调一致。

### 2.2 对比度原则

- 正常文字与背景对比度 ≥ 4.5:1
- 大文字（>18pt）与背景对比度 ≥ 3:1
- UI 组件及图标与背景对比度 ≥ 3:1

### 2.3 主题系统

| 主题 | 适用场景 | 色板方向 |
|------|---------|---------|
| Dark（默认） | 代码编辑、低光环境 | 深色背景 + 浅色文字 |
| Light | 文档阅读、高光环境 | 浅色背景 + 深色文字 |
| HighContrast | 无障碍需求 | 极高对比度配色 |

**切换原则**：通过主题服务统一切换，切换时窗口整体过渡（200ms ease-in-out），编辑器即时切换。所有颜色定义集中在主题服务，UI 组件通过主题变更信号更新颜色，禁止任何组���中硬编码颜色值。

## 3. 布局原则

### 3.1 度量系统

- **基础单位**：4px。所有间距、内边距、组件尺寸基于 4px 的倍数。
- **窗口边距**：16px
- **面板间距**：8px
- **组件间距**：4px
- **组内间距**：8px

### 3.2 窗口约束

- **最小窗口**：800×600
- **默认窗口**：1200×800
- **侧栏宽度**：180px~400px（可拖动调节）

### 3.3 主窗口布局（Z-order 从低到高）

```
[Title Bar]
[Menu Bar]
[Command Bar（可选）]
[Tab Bar | Editor（分屏）| Search Results Panel（可选）]
[Status Bar]
```

### 3.4 分屏原则

- 支持垂直/水平分割
- 每个分屏为独立编辑器实例
- 最大 4 个分屏（2×2 网格），递归分割深度 ≤ 2 层
- 焦点编辑器以更粗边框指示，操作默认作用于焦点编辑器

---

## 4. 排版原则

### 4.1 字体回退策略

- **UI 字体**：优先使用 Segoe UI → 微软雅黑 → PingFang SC → Noto Sans CJK SC → 系统无衬线字体
- **等宽字体**：优先使用 Cascadia Code → JetBrains Mono → Fira Code → Source Code Pro → Consolas → 系统等宽字体

### 4.2 字号层级

| 层级 | 字号 | 用途 |
|------|------|------|
| caption | 11px | 状态栏、行号 |
| body | 12px | 正文、菜单 |
| body_large | 14px | 对话框 |
| subtitle | 16px | 次级标题 |
| title | 20px | 标题 |
| title_large | 28px | 大标题 |

### 4.3 编辑器排版

- 默认等宽字体 13px，范围 10~40px，缩放步进 1px
- 字体连字默认启用，可在设置中关闭

---

## 5. 图标原则

- **图标集**：统一使用一套图标系统，风格为线性轮廓模式
- **尺寸**：小 16×16（工具栏/状态栏）/ 中 20×20（菜单项/列表项）/ 大 24×24（命令栏/首屏）
- **规则**：所有菜单项和工具栏按钮必须带图标，图标语义与操作匹配，禁止使用 Unicode 字符替代图标

---

## 6. 对话框原则

| 类型 | 用途 |
|------|------|
| 模态 | 设置、查找替换、转到行、统计、哈希、信息、警告、错误、确认 |
| 非模态 | 搜索结果面板、Minimap |

**通用规则**：
- 居中于父窗口
- 标题以动词开头
- 宽度 ≤ 父窗口 80%，高度 ≤ 90%
- 内边距 16px
- 按钮顺序：[确认][取消]
- Esc 关闭，Enter 触发主要操作
- 设置对话框：分组展示，变更实时生效，关闭时自动保存

---

## 7. 动画原则

| 场景 | 时长 | 类型 |
|------|------|------|
| 按钮悬停 | 100ms | 颜色过渡，OutCubic 缓动 |
| 标签切换 | 150ms | 淡入 |
| 菜单展开 | 150ms | 弹出 |
| 搜索栏显示 | 200ms | 从上滑入 |
| 搜索高亮反馈 | 300ms | 闪烁/淡出 |
| 状态栏消息 | 300ms | 淡入淡出 |
| 主题切换 | 500ms | 全局渐隐过渡 |

**可访问性**：所有非必要过渡动画应可通过设置禁用，仅保留必要视觉反馈（如按钮状态变化）。

---

## 8. 无障碍原则

- **键盘导航**：所有功能可通过键盘完成，Tab 顺序按逻辑遍历（菜单栏 → 编辑器 → 搜索栏）
- **聚焦指示**：聚焦元素有清晰视觉指示（accent 色虚线边框）
- **字体缩放**：编辑器字体独立于 UI 字体缩放，UI 字体通过系统 DPI 配置适配

---

## 9. 响应式原则

- **宽度变化**：编辑器内容区弹性伸缩，搜索栏宽度同步伸缩，状态栏左侧弹性右侧固定
- **高度变化**：编辑器内容区弹性伸缩，行号区同步伸缩，标签栏/菜单栏/状态栏高度固定
- **缩至最小（800×600）**：隐藏非核心功能（命令栏收起、搜索栏收起为浮动图标、侧栏自动隐藏）
- **DPI 适配**：所有 UI 尺寸基于逻辑像素，DPI 变更时字体/图标/间距/组件尺寸自动缩放

## 11. UI 性能目标

| 指标 | 目标 |
|------|------|
| 输入延迟 | <16ms (60fps) |
| 滚动帧率 | ≥30fps（大文件）|
| 语法高亮 | <500ms |
| 搜索高亮 | <200ms |
| 窗口打开 | <500ms |
| 标签切换 | <100ms |
| 对话框打开 | <200ms |
| 主题切换 | <300ms |

**大文件策略**：
- <1MB：正常加载 + 完整高亮
- 1-5MB：完整加载 + 高亮
- 5-10MB：完整加载 + 降级高亮
- >10MB：只读模式 + 无高亮（后台线程分段读取，首屏优先渲染，禁用自动换行和实时行号计算）

---

## 12. 文档维护

1. 修改颜色/字号/间距令牌时更新第 2/3/4 节对应色板
2. 新增动画效果更新第 7 节
3. 新增主题色更新第 10 节
4. 违反规范在代码审查中标记
5. 重大视觉变更需整体过一致性
