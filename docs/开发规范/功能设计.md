# 功能设计 —— 功能模块清单

> 本文档是 GlassEditor 的**功能模块总览与索引**：给出每个模块的层级、职责与详细设计文档的对应关系。
> 文档分工：架构约束以 `设计架构规范.md` 为准；数据流与状态以 `信息架构文档.md` 为准；
> 操作流程以 `交互设计说明.md` 为准；视觉规范以 `UI设计规范.md` 为准。
>
> 更新约定：新增/删除/迁移模块时同步更新本清单（架构规范 §1"功能修改同步更新文档"）。

---

## 1. 分层模块清单

### 1.1 UI 层（`src/ui/`）

| 模块 | 文件 | 职责 |
|------|------|------|
| MainWindow | `main_window.py` | 编排器：布局与命令栏、服务装配、信号编排、会话恢复、CLI 参数落地 |
| CodeEditor | `code_editor.py` | 编辑器控件：行号槽、括号匹配、多光标、搜索高亮、配色应用 |
| EditorTabWidget | `editor_tab_widget.py` | 标签容器：欢迎页、拖拽排序、stackedWidget 管理 |
| SyntaxHighlighter | `syntax_highlighter.py` | Pygments 高亮器与工厂 `create_highlighter`，>5MB 降级 |
| MenuBarManager | `menu_manager.py` | 菜单栏内容与菜单构建（信号驱动，不执行业务） |
| StatusBar | `status_bar.py` | 状态栏：光标、编码、行尾、语言、缩放（编码可点击切换） |
| SearchBar | `search_bar.py` | 内联查找栏（150ms 搜索延迟） |
| SearchResultPanel | `search_result_panel.py` | 多文件搜索结果树与导航 |
| SplitViewManager | `split_view_manager.py` | 分屏创建/关闭与 QSplitter 管理 |
| WelcomePage | `welcome_page.py` | 欢迎页：快捷键速查、主题切换、新建/打开入口 |
| SettingsPage | `settings_page.py` | 设置页：外观/编辑行为/系统托盘/快捷键四组卡片，ConfigKey 读写 |
| SystemTrayIcon | `system_tray_icon.py` | 系统托盘图标与托盘菜单 |
| Dialogs | `dialogs/` | find_replace、goto_line、statistics、hash（经 DialogCoordinator 工厂延迟创建） |

### 1.2 Controller 层（`src/controller/`）

| 模块 | 文件 | 职责 |
|------|------|------|
| SignalBus | `signal_bus.py` | 全局信号总线单例，**10 个信号**（清单见设计架构规范 §4.2） |
| ActionManager | `action_manager.py` | 动作注册、快捷键管理、全部槽函数（每槽 try-except） |
| TabManager | `tab_manager.py` | 标签生命周期、文件外部修改监听、会话保存、编码转换 |
| FocusManager | `focus_manager.py` | 焦点侧状态、分屏编辑器引用、各屏标签索引 |

### 1.3 Service 层（`src/service/`）

| 模块 | 文件 | 职责 |
|------|------|------|
| FileService | `file_service.py` | 文件打开/保存/重载、编码检测、行尾、最近文件 |
| SearchService | `search_service.py` | 查找替换正则逻辑与匹配状态 |
| ThemeService | `theme_service.py` | 颜色方案（暗/亮/高对比）、Fluent 主题切换、编辑器配色（QSingleton） |
| ConfigService | `config_service.py` | pydantic 配置校验与读写、会话保存/加载 |
| SyntaxService | `syntax_service.py` | 扩展名→语言映射 |
| ToolService | `tool_service.py` | 纯静态文本工具：字数统计、文本/文件哈希、排序去重、大小写转换 |
| DialogCoordinator | `dialog_coordinator.py` | 对话框延迟创建（importlib 工厂）、消息与文件对话框 |
| SyntaxHighlighterManager | `syntax_highlighter_manager.py` | 高亮器生命周期：创建、配色更新、语言切换 |

### 1.4 Infrastructure 层（`src/infrastructure/`）

| 模块 | 文件 | 职责 |
|------|------|------|
| Settings | `settings.py` | JSON 配置读写、500ms 去抖、原子写入（Singleton + RLock） |
| FileIO | `file_io.py` | 底层文件读写与原子写入（atomicwrites） |
| Logger | `logger.py` | Loguru 日志配置（遵循日志系统设计规范） |
| Singleton | `singleton.py` | Singleton / QSingleton 元类 |
| ShortcutRegistry | `shortcut_registry.py` | 快捷键持久化与冲突检测（Singleton） |
| AppConstant | `app_constants.py` | 数值常量集中管理（含 `HASH_CHUNK_SIZE`、`LARGE_FILE_THRESHOLD` 等） |
| ConfigKey | `config_keys.py` | 配置键名集中管理（禁止字符串字面量） |
| EncodingDetector / EncodingUtils | `encoding_detector.py` / `encoding_utils.py` | BOM+chardet 检测；编码分组、显示名、转换核心逻辑 |
| CLIArgs / SingleInstance | `cli_args.py` / `single_instance.py` | 命令行参数数据类；单实例 IPC 守卫 |

### 1.5 Lib（第三方嵌入，`src/lib/`）

| 模块 | 状态 | 说明 |
|------|------|------|
| `trid/`（TrID，AGPL-3.0） | **预留未接线** | 库与 `triddefs.trd` 已嵌入但无调用点，`trid.py` 尚未提供文档所述封装 API；接入前评估许可风险（设计架构规范 §2/§10、`docs/TrID/`） |
